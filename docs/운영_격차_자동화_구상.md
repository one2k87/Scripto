# 운영 격차 자동화 구상 (2026-09-05)

Claude가 수작업으로 대행해온 운영 작업과 스크립토/픽토 앱 기능 사이의 격차를 실측 기준으로 정리하고,
자동으로 메꾸는 시스템을 설계한다. 원칙: **내가 겪은 문제 = 제품 기능**.

## 2. 시스템 설계: 대시보드 「유지관리(Ops)」 패널

설정탭 하위에 신설. 전부 기존 ghToken(workflow_dispatch API) 재사용이라 백엔드 추가 없음.

- **원탭 실행 버튼**: 이미지 전체 재교체(force 토글 포함) / 기본 콘텐츠 정리 / 사이트 점검 / 주간 전략.
  실행 → Actions 링크 표시 → 완료 시 텔레그램(기존).
- **할 일 인박스 연동**: daily_check_fix.py에 검사 추가 — ①기본 글 존재 ②이미지 v2 마커 없는 글 수.
  발견 시 인박스 카드 "기본 글 2건 정리 필요 → [지금 정리]" (버튼 = cleanup.yml dispatch).
  → 신규 이용자는 아무것도 몰라도 인박스만 따라가면 운영이 됨.
- **연결 마법사(로그인 필요 항목)**: GSC / 네이버 서치어드바이저 / 애드센스 — 상태 뱃지(연결·미확인) +
  딥링크 + 확인 절차 1분 체크리스트. 자동 검증은 공개 신호(사이트맵 fetch, robots)까지만.

구현 순서 제안: ①버튼 4종(반나절) → ②인박스 검사 2종 → ③이미지 정책 설정화 → ④연결 마법사 뱃지.
