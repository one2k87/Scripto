## 성장 구조(기록 → 학습 → 배포)
1. 모든 모듈은 `modules/<이름>/` 아래 `rules.json`(프롬프트·임계값)과 `CHANGELOG.md`(버전·이유·근거 데이터)를 가진다. 코드는 고정, 성장은 규칙 파일로.
2. 각 글에 `module_versions`(예: title@1.3, body@2.0)를 남겨, 점검 결과를 어느 모듈 버전이 만든 글인지로 나눠 볼 수 있게 한다.
3. 개선 엔진은 「이 모듈 이 버전이 성과가 낮다」를 지목하고 수정안을 만든다. 적용은 A/B(새 글 절반만) → 2주 비교 → 이기면 승격.
4. 이용자가 늘면: 이용자 동의(옵트인) 시 글 본문 없이 「모듈 버전·분야·성과 수치」만 익명 집계 → 검증된 규칙 팩을 업데이트로 배포. 학습은 모델 학습이 아니라 규칙·프롬프트 갱신.
