# 🧭 4액션 가이드 — 스크립토 패밀리 제품화 북극성

작성 2026-09-03 · 상태: **대기 (스타트 조건 = 애드센스 승인)** · 6회차 신청 진행 중

## 북극성 선언

> **사용자가 하는 일은 평생 4개를 넘지 않는다.**
>
> ① 회원가입 → ② 니치 3문답 → ③ 결제 → ④ 쿠팡 파트너스 ID 입력 — 끝.
>
> 그 외 모든 것(호스팅·도메인·워드프레스·시크릿·크론·색인·채널·영상)은 시스템 또는 운영자(컨시어지)가 흡수한다.
> 새 기능을 만들 때마다 묻는다: **"이게 사용자 액션을 5개로 만드는가?"** — 그렇다면 설계를 다시 한다.

## 1. 왜 4액션인가 — 실측된 마찰 전수 목록

픽담(pickdam.com) 개통 실측(2026-09-01~03)에서 사용자/운영자가 실제로 수행한 일과, 4액션 세계에서 그것을 누가 흡수하는지:

| 실측 마찰 | 난이도 | 4액션 세계의 흡수처 |
|---|---|---|
| 도메인 구입(가비아)·네임서버 변경 | 중 | ③결제에 포함 — 시스템이 프로비저닝(도메인 자동 등록 or 서브도메인 제공) |
| 카페24 결제·플랜 선택 함정(700MB) | 중 | ③결제에 포함 — 호스팅 리셀/제휴로 내재화 |
| 도메인 연결 '오류'(전파 전 연결)·재연결 | **상** | 시스템 — 자동 재시도 로직(이미 절차 확보) |
| SSL 발급·대표 도메인 전환 순서 | 상 | 시스템 — 상태 폴링 후 자동 전환 |
| WP 앱 비밀번호 발급·전달 | 중 | 시스템 — WP 프로비저닝 시 자동 생성 |
| GitHub 저장소·토큰·시크릿 8종 | **최상** | **소멸** — 중앙 러너(Phase 5)로 이전, 사용자 세계에서 GitHub 자체가 사라짐 |
| 크론 지각·백업·중복 가드 튜닝 | 상 | 소멸 — 중앙 스케줄러 |
| 방화벽 403(script 차단) 디버깅 | 최상 | 소멸 — publisher 자가 수리로 이미 코드화 |
| 서치콘솔 DNS TXT·사이트맵 | 상 | 시스템 — 도메인 프로비저닝 시 TXT 자동 삽입 + Site Kit |
| IndexNow 키 발급·심기 | 중 | 시스템 — 이미 자동화됨 |
| 쿠팡 파트너스 가입·ID | 중 | **④로 유지** — 본인 명의 필수라 유일하게 사용자 몫 |
| 채널 개설·영상 업로드(캐스토) | 중 | 시스템(Make 자동 게시) + 온보딩 마법사의 OAuth 연결 |

결론: 12개 마찰 중 사용자에게 남는 것은 **1개(쿠팡 ID)** 뿐이어야 한다.

## 2. 4액션 상세 스펙

**① 회원가입** — 이메일 또는 구글 로그인 1탭. (Supabase Auth)
**② 니치 3문답** — "관심 분야는? / 하루 몇 분 쓸 수 있나? / 목표는 승인·수익 중 무엇부터?" → 승인 확률 데이터(quality_log 축적분)로 니치 자동 추천. '맡길게요' 버튼 제공.
**③ 결제** — 월 구독 1건에 호스팅·도메인·SSL·발행·색인·(플랜별)영상까지 포함. 결제 완료 순간 백엔드가 WP 프로비저닝→연결→검증→첫 글 예약까지 무인 진행, 진행 상황은 "개통 중 🟢🟢⚪" 스테퍼로만 노출.
**④ 쿠팡 파트너스 ID** — 픽 라인 선택자만. 가입 딥링크+화면 캡처 가이드 제공, ID 붙여넣기 1회. (API 개방 시점엔 API 키 1회 추가 — 예외 인정)

이후 사용자의 일상 = **텔레그램/앱 알림을 읽는 것뿐.** 개입이 필요한 예외는 전부 "버튼 1개"로 환원해 알림에 담는다(현행 할 일 인박스 원칙 유지).

## 3. 전환 로드맵 — 스타트 조건: 애드센스 승인 ✅

승인은 "이 시스템이 진짜 작동한다"는 증명서다. 증명 없이 팔지 않는다.

| 단계 | 트리거 | 내용 | 사용자 액션 수 |
|---|---|---|---|
| **G0 대기(지금)** | — | 픽담·캐스토 무인 운영으로 시스템 숙성, 함정 계속 수집 | (본인만) |
| **G1 컨시어지 β** | **승인** | 와이프 계정으로 대행 리허설 — 위 표의 '시스템' 항목을 사람+Claude가 수동 대행하며 시간 측정 | 4개 목표로 리허설 |
| **G2 유료 컨시어지** | β 1건 성공 | 승인 패키지 판매(99,000원~) — 대행 매뉴얼로 원가 절감, 고객 마찰 로그가 SaaS 요구사항이 됨 | 4개+α (임시 허용) |
| **G3 SaaS** | 컨시어지 5~10건 or 대행 병목 도달 | Phase 5: Supabase + 중앙 러너 + WP 자동 프로비저닝 — GitHub·시크릿 소멸 | **4개 확정** |

- G1~G2에서 대행 1건당 소요 시간을 기록한다 — 시간이 줄지 않는 항목이 G3 자동화 1순위.
- 졸업 기준(G2→G3): 대행 1건 2시간 이내 재현 가능 + 매뉴얼 없이 못 하는 단계 0개.

## 4. 지금(대기 중) 해도 되는 준비 — 승인과 무관한 것만

- 픽담·캐스토 운영 지속(캐스토 v1은 힉스필드 키·채널 오는 대로) — G1의 상품 데모가 됨
- 신규 함정 발생 시 즉시 코드/문서화(현행 원칙) — 이 문서의 표에 행 추가
- 대행 매뉴얼 초안은 _Master_Context 기록이 이미 그 역할 — 별도 작업 불필요

**이 문서의 사용법**: 모든 신규 기능·개편 논의에서 "4액션을 지키는가"를 첫 질문으로 삼는다. 승인이 떨어지면 G1부터 순서대로 연다.
