환경설정의 글자 크기를 아무리 키워도 잠금화면 시계는 그대로 작게 남아있어 당황하셨을 겁니다. 갤럭시 s24 잠금 화면 설정 시계와 위젯 글자 크기 키우는 방법 3단계는 일반 글자 크기 메뉴가 아니라, 잠금화면 전용 편집 화면에서 시계 상자 틀 자체를 직접 늘려주는 방식으로 해결합니다. 2026년 11월 기준 삼성전자 최신 소프트웨어(One UI 6.1 이상)가 적용된 갤럭시 S24 시리즈는 화면 빈 곳을 2초간 꾹 누르는 것만으로 즉시 조절 막대를 불러올 수 있습니다.

손끝으로 바로 여는 잠금화면 편집 창과 조절 막대

설정 메뉴를 복잡하게 찾아 들어갈 필요가 없습니다. 화면이 켜진 상태에서 잠금을 풀고, 알림이나 시계가 없는 빈 바탕 화면을 2초 동안 손가락으로 꾹 누릅니다. 화면이 살짝 뒤로 물러나며 테두리가 생기면 편집 준비가 끝난 상태입니다. (저는 처음에 지문 센서 부근을 눌렀다가 인식이 안 되어 화면이 꺼지기도 했습니다.)

더 많은 정보는 아래에서 확인해보세요.

화면 상단의 시계 숫자를 손가락으로 톡 건드립니다. 시계 둘레에 하얀 사각형 틀과 함께 모서리에 작은 조절점 4개가 나타납니다. One UI 6.1에서 가장 헷갈리는 지점이 바로 여깁니다. 하단 글꼴 목록만 넘겨서는 글자가 커지지 않습니다. 시계 틀 오른쪽 아래 모서리에 있는 작은 동그라미를 대각선 바깥 방향으로 쓱 끌어당겨야 숫자가 시원하게 커집니다. 원하는 크기까지 늘린 다음 오른쪽 상단의 '완료' 글자를 누르면 저장이 끝납니다. 대략 1분도 걸리지 않는 작업입니다.

자세한 시계 스타일 변경 방법은 갤럭시 잠금화면 시계와 알림 설정 가이드에서 함께 점검할 수 있습니다.

상황별 화면 표시 방식 비교와 설정 분기

시계를 무조건 최대로 키우는 것만이 정답은 아닙니다. 함께 배치한 날씨나 일정 위젯의 개수, 그리고 꺼진 화면(AOD) 사용 여부에 따라 화면 구성이 완전히 달라집니다. 아래 기준표를 보고 본인의 사용 습관에 맞춰 크기를 결정합니다.

사용 상황 시계 크기 권장 주의할 점
날씨·배터리 위젯 2개 이상 배치 중간 크기 (기본값에서 2단계 확대) 시계를 끝까지 키우면 하단 위젯이 밀려나 사라집니다.
위젯 없이 시계·날짜만 확인 최대 크기 (모서리 끝까지 확장) 배경 화면 인물 얼굴이나 풍경 중심부가 가려질 수 있습니다.
꺼진 화면(AOD) 시계 공유 시 상단 고정형 표준 크기 Always On Display 연동 시 배터리 소모량이 소폭 늘어납니다.

꺼진 화면 시계까지 함께 바꾸고 싶다면 AOD 및 잠금화면 시계 조절 안내를 대조해 보는 것도 방법입니다.

자주 발생하는 실패 유형과 자녀 통화 스크립트

흔한 실수 중 하나는 시계 틀을 너무 크게 잡아당겨 아래쪽 알림 목록 아이콘과 겹쳐버리는 현상입니다. 만약 크기를 늘리다가 모양이 찌그러지거나 마음에 들지 않는다면, 당황하지 말고 화면 왼쪽 위의 '취소'를 누릅니다. 원래 모양으로 즉시 돌아갑니다. 잘못 만져서 기기가 망가지는 일은 절대 없으니 안심해도 좋습니다.

⚠️ 여기서 멈추고 확인: 시계 스타일을 바꿀 때 글꼴 목록 맨 끝에 있는 다운로드 버튼(화살표 모양)은 누르지 마세요. 유료 글꼴 결제 창으로 넘어갈 수 있으므로 기본으로 제공되는 6개 글씨체 안에서만 고릅니다.

전화로 알려드릴 때는 이렇게 말하세요: "화면 켜고 빈 곳을 2초 동안 꾹 누르면 테두리가 나와. 시계를 톡 누르고 오른쪽 아래 작은 동그라미를 바깥으로 쭉 당긴 다음, 맨 위에 '완료' 누르면 끝이야."

관련 자료가 궁금하다면 다음 내용을 참고하세요.

원격 지원이 필요하다면 삼성전자 공식 스마트스위치나 'Samsung Smart Tutor(원격 지원)' 앱을 통해 통신사나 기기 제약 없이 도움을 받을 수 있습니다. 순서를 지키지 않고 잠금 화면을 끈 채 전원 버튼만 반복해서 누르면 긴급 전화 화면으로 넘어갈 수 있으니, 반드시 잠금을 먼저 풀고 빈 공간을 2초간 누르는 첫 순서부터 차근차근 진행합니다.

자주 묻는 질문

잠금화면 빈 곳을 길게 눌러도 편집 화면으로 안 바뀝니다.

지문 인식이나 비밀번호 잠금이 풀리지 않은 상태일 수 있습니다. 화면을 켜고 잠금을 먼저 푼 직후, 알림 창이 없는 빈 바탕을 2초 동안 꾹 누르면 편집 모드로 들어갑니다.

시계 글자 크기를 키우면 날씨나 배터리 위젯은 어떻게 되나요?

시계 틀을 최대로 키우면 아래쪽 위젯 공간이 좁아져 위젯이 한 줄로 줄어들거나 배치가 아래로 밀립니다. 시계와 보조 위젯의 비율을 맞추려면 모서리를 조금씩 당겨 화면 균형을 보면서 조절합니다.

글씨 크기를 키웠는데 화면이 이상해지면 원래대로 돌릴 수 있나요?

편집 화면 우측 상단의 '완료'를 누르기 전이라면 왼쪽 상단 '취소'를 눌러 이전 상태로 되돌립니다. 이미 완료를 눌렀더라도 편집 화면에 다시 들어가 기본 시계 모양을 누르면 처음 크기로 즉시 복원됩니다.
